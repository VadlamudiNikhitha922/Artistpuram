# Artistpuram — Home Page Starter

This is the first frontend step for the Artistpuram website. It currently contains the homepage only.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this ZIP.
3. Open a terminal in the extracted `artistpuram-homepage` folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite in your browser.

## What's included

- Artistpuram text-based temporary logo (can be replaced when the real logo is ready)
- Scrolling booking announcement ribbon
- Responsive navigation
- Hero / introduction section
- Small sample art cards for resin art, crochet art, pipe cleaner art, Lippan art, and tote bag painting
- Artist note section
- Contact section
- Footer links for Privacy Policy, Contact Us, and Help

## Important before publishing

- The booking ribbon currently shows sample text. It is not connected to a live booking system yet.
- Images are illustrative placeholders loaded from Unsplash and require an internet connection. Replace them with the owner's actual artwork before publishing.
- `hello@artistpuram.com` and the other contact labels are placeholders. Replace them with verified owner contact details.
- Privacy Policy and Help are footer placeholders for now, not full pages.
- The owner dashboard, secure login, image uploads, event management, and live booking management will be built in later steps. This homepage is frontend-only.
